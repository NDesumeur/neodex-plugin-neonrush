# Néon Rush

Course sans fin sur trois voies dans une ville néon : saute les barrières, glisse sous les panneaux, change de voie avant le métro, ramasse les pièces.

Flèches gauche / droite (ou A / D) : changer de voie. Haut, W ou espace : sauter. Bas ou S : glisser. À la souris ou au doigt : glisse dans la direction voulue. La vitesse monte avec la distance.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Néon Rush → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
